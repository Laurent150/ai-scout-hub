# AI Scout Hub

AI 行业情报站：**日报 · 动态追踪 · 产品能力**

**在线查看 → [laurent150.github.io/ai-scout-hub](https://laurent150.github.io/ai-scout-hub/)**

页面会持续更新。想跟每天的内容，直接打开上面的链接即可，不必 fork 或本地搭建。

## 三个栏目

- **日报**：当天值得看的 AI 动态摘要
- **动态追踪**：按公司 / 产品筛选的事件时间线
- **产品能力**：有出处的官方或第三方能力数字与图表（不做估算）

每条摘要和数字都带来源链接；站点为单个静态页面，可离线打开。

## About

AI Scout Hub 用来集中查看 AI 产品与行业动态，方便对照来源，而不是再刷一遍散落的资讯流。

内容由维护者持续整理后发布到本站。本仓库主要托管已发布的页面；日常采集与写作不在此仓库内运行，因此 fork 后不会自动收到每日更新。

数据原则很简单：能写进「产品能力」的，必须是官方数字或可核对的第三方测评；媒体里只出现名字、没有可引用成绩的，留在动态追踪里。

有问题或建议，欢迎开 Issue。
